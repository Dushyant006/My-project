# Dockerized Python Version & Time App (Assignment 15)

A simple, lightweight Dockerized Python application built using `python:3.12-slim` that outputs the current running Python version along with the container system date and time.

## Project Structure
* `main.py` - The core Python script.
* `Dockerfile` - Configuration to containerize the application.
* `README.md` - Documentation.

## Prerequisites
Before running this project, ensure you have the following installed:
* [Docker Desktop](https://www.docker.com/products/docker-desktop/)
* [Git](https://git-scm.com/)
